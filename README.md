# Musarrat Restaurant Replica

Static deployment bundle for the local Musarrat Restaurant replica.

## Deploy

Deploy the contents of this folder as a static site root:

- `index.html`
- `css/`
- `js/`
- `images/`
- `fonts/`

This works on common static hosts such as Netlify, Vercel static hosting, GitHub Pages, Cloudflare Pages, or any basic web server.

## Notes

- Main entry: `index.html`
- Local assets use relative paths
- `Order online` buttons stay inside the replica and scroll to `#section-menu`
- Google Translate should work because the page fixer only runs once on load

## Recommended publish directory

`restaurant-replica`
